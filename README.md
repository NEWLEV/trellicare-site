# Trellicare website

Static, GitHub Pages–friendly marketing site for Trellicare, the care-coordination platform for Ryan White programs.

## Run locally

Open `index.html` directly, or serve the directory with any static server:

```bash
python3 -m http.server 8080
```

The demo form is intentionally front-end only until a CRM destination and calendar link are approved. It collects business contact information only and contains no patient data or PHI.
